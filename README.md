지금까지의 휴먼교육센터에서 배운 java를 공부해보고자 한다.
java는 객체지향 프로그래밍 언어이다.
기본 자료형을 제외한 요소들이 객체로 표현되고, 객체 지향 개념의 특징인 캡슐화,상속,다형성이 있다.
객체는 부품이다. 클래스는 설계도이다.
클래스는 객체를 만들기 위해 정의되어있다.
클래스는 멤버변수와 메서드로 구성
클래스로부터 만들어진 객체는 독립적이다.
변수는 원시변수와 참조변수가 있는데, 원시변수는 int 참조변수는 앞이 대문자 String
참조변수는 주소를 저장하고 객체는 자바의 힙영역에 저장된다.
참조변수가 저장하고 있는 주소값으로 객체에 접근한다.
생성자는 객체를 만들 때 처음 호출되는 메서드이다.
생성자는 클래스 이름과 동일하다.
