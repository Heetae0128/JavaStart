인터페이스는 추상메서드만 사용 의존도를 낮추기위해

public interface MemberDAO(){
	public void add();
	public void del();
}

tiger라는 클래스에 memberDAO m = new 구현받을 클래스명; 라고 객체를 생성하면
m.구현받을클래스의 메소드를 사용가능  >  이말은 즉, 의존도를 낮추는것
